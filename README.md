# 石冢 · 后山古墓

[TARP](https://jointarp.party) 官方示例模组，使用简化改编的《石冢》（Cairn）第一版规则，仅用于快速体验 TARP 的冒险内容与玩法，支持独行或两人同行。规则以本模组手册为准，完整原版规则请参阅 Cairn 第一版 SRD。

后山滑坡露出一座古墓，前来寻宝的你听见门内深处传来求救声。带上有限的照明与工具，探索墓道、应对危险，寻找归途。

模组提供两名预设角色，包含探索、交涉、战斗与资源管理。玩法说明见 [模组概览](module/概览.md) 和 [玩家手册](module/玩家手册.md)。

## 使用

在 TARP 中选择「导入模组 → Git」，填写：

- 仓库地址：`https://github.com/joinTARP/cairn-houshan-tomb.git`
- 分支：`main`

导入后新建冒险即可游玩。完整模组位于仓库的 `module/`，也可将该目录复制到 TARP 设置中的模组保存路径。
