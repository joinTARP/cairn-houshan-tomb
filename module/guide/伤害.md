---
name: 伤害的裁定与记录
---

体力代表在危险中闪避、招架和承受冲击的余裕。体力耗尽仍可行动，但之后受到的伤害会直接损伤力量；恰好被伤害耗尽体力时，仍按伤疤规则处理。

## 伤害与两种触发

攻击直接掷伤害骰。实际伤害为 **max(0，骰点－目标护甲)**。宝藏猎人与人物的当前护甲由实际穿着的装备计算；皮甲提供 1，脱下或不再持有即不提供，读取当前 armor。怪物继续使用自己的护甲资料。先扣当前体力，超出体力的余伤立即扣力量，数值最低为 0。保留受伤前体力，按以下顺序处理：

1. 力量降至 0：立即死亡，宝藏猎人或人物写 `injury.state=死亡`、期限为 -1、aid_received=false。
2. **实际伤害超过受伤前体力，且力量仍大于 0：**先扣力量，再掷 1d20，用**受伤后的当前力量**做重伤豁免。1 总成功，20 总失败。体力已为 0 时受到正伤害，同样需要这次豁免。
3. **受伤前体力大于 0，实际伤害恰好等于该体力：**宝藏猎人按[[guide/伤疤]]查表，没有余伤，不额外做重伤豁免。NPC 与怪物不获得玩家伤疤。
4. 伤害不足以耗尽体力，或护甲把伤害减至 0：只处理实际扣值。

例如体力 3、力量 12、护甲 1，骰点 7：实际伤害 6，体力变为 0、力量变为 9，再以力量 9 做重伤豁免。骰点 4 则实际伤害 3，体力恰好归零，宝藏猎人查伤疤表第 3 项。

满载把体力压至 0 不是伤害，**不触发伤疤或重伤豁免**。体力 0 本身不等于死亡或不能行动；还须检查重伤、伤疤和属性限制。

## 重伤与救助

未受重伤时省略 `injury.state`，不填写“无”；仅记录“重伤未稳定”“重伤已稳定”或“死亡”。未受重伤时仍保留 `injury.aid_received=false`、`injury.death_deadline_turn=-1`。省略状态只表示没有重伤，不代表体力或属性没有损伤。既有重伤须按规则处理，稳定后保留“重伤已稳定”，不能靠删除状态解除伤势；只有按恢复规则完成康复后才移除状态，并重置救助标记和期限。

宝藏猎人与顾遥重伤豁免成功时，保留力量损伤，不自动解除先前重伤。失败时写 `injury.state=重伤未稳定`，只能虚弱爬行，不能攻击、正常移动、攀井或自行完成救助。第一次未稳定时，`injury.death_deadline_turn` 写受伤时的 exploration_turn 加 6；再次受伤不能延后已有的较早期限。每次新受重伤把 `injury.aid_received` 设为 false，需要重新施救。

同伴施救后，伤者还须休息，普通重伤才能稳定。战斗中施救占一项行动，实际完成后保存 `injury.aid_received=true`；随后仍须脱离即时威胁并完成 1 探索回合休息；必须在死亡期限前完成。写 `injury.state=重伤已稳定`、期限为 -1，停止失血死亡计时。力量损伤保留；稳定后按剩余属性及伤疤限制行动，体力恢复另按[[guide/休息与恢复]]。单纯喝水、吃饭、体力回满或站到井口不会自动稳定伤者。

未及时稳定者到期限时死亡，写 `injury.state=死亡` 并清除期限和 aid_received，即使力量仍大于 0 也不能行动。伤疤第 11 项须实际治疗，第 12 项影响下一次重伤豁免，优先依伤疤规则处理。

力量 0 为死亡；敏捷 0 无法自行移动；意志 0 神志紊乱、无法行动。同伴可以搬运、保护和救出伤者，但伤者尚未死亡，并不代表能够自行攀井。生死以计算字段 `alive` 为准，结局见[[guide/死亡与结局]]。

## 怪物

怪物逐只保存 `member_hp`、`member_strength` 与 `member_critical`，同序号对应同一成员。体力归零不等于击败；余伤扣该成员力量，再以剩余力量做重伤豁免。失败写 `member_critical=true`，失去战斗能力；力量 0 同样击败。豁免成功且力量大于 0 者仍可行动，之后正伤害全扣力量并再次豁免。

怪物不查伤疤表。本次遭遇中重伤失能者视作已击败。`count` 是仍能战斗的成员数，与总体力不等价；危险是否清除应检查 `count` 和实际隔离状态。

## 属性字段的含义

角色 `hp` 表示闪避、招架与承受冲击的余裕；`max_hp`、`max_attributes` 是固定开局上限，伤疤不改变它们。`alive` 从当前力量与伤势状态派生，不以体力判定生死。顾遥按人物伤害规则处理，不使用玩家伤疤表。实际施救、休息与治疗必须完成。
