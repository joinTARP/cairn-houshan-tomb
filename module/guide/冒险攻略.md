---
name: 后山古墓主持攻略
---

滑坡露出后山古墓，宝藏猎人赶来寻宝，门内传来女子的求救声。冒险从墓门外开始，玩家决定如何入墓；入墓后退路坍塌，须寻找另一出口，取宝由玩家决定。可选择 [[character/陆川]] 或 [[character/苏棠]] 独行，也可两人同行。

## 路线

墓门 ↔ 甬道 ↔ 陪葬耳室 ↔ 殉葬室 ↔ 棺室 ↔ 后洞 ↔ 老井口。六个探索区域，老井口是墓外安全处。完整路线随探索揭示。

| 地点 | 现场与取舍 |
| --- | --- |
| [[location/墓门]] | 门下碎石撑着窄缝，门口有自然光，深处有人求救。准备与入墓按玩家行动处理，全员进入后才封堵入口。 |
| [[location/甬道]] | 北门铜闩牵动门楣摆刃。门前凿痕、刀槽和连杆可供检查；按玩家的布置判断刀路、支承与通路。机关见 [[guide/甬道机关]]。 |
| [[location/陪葬耳室]] | 失明干尸被铁链拴住，靠声音追人。铁链、石柱和声源决定它能靠近哪里；东墙工具与铜钱可选取。 |
| [[location/殉葬室]] | 出口在塌坑对面，梁端不稳。木料、石槽、门柱和坑壁石缝可供利用，按支承与搬运安排裁定。见 [[guide/殉葬室机关]]。 |
| [[location/棺室]] | 东墙裂缝直接通向后洞。棺缝漏冷光，里面有刮擦声；是否开棺由玩家决定。开盖、限制和封回依据实际装置与位置处理，珠与剑各只有一件。 |
| [[location/后洞]] | 墓鼠见人退避。健康队攀井作为一个完整目标，有光 1 回合、无光 2 回合；真正不能自行攀爬者才加搬运时间。 |

敌人活动范围见各自资料，取宝不引发全墓追杀。

## 开场与顾遥

冒险从墓门外开始，预写开场发送外景图。按 [[location/墓门]] 处理实际入墓、登记与随后封门。墓门与甬道资料公开，顾遥初始隐藏，由主持按 [[npc/顾遥]] 手动揭露。

顾遥是躲避滑坡误入的村民，与宝藏猎人原不相识。她在甬道北门之后：先前敞开的门因震动回转、外闩落扣，把她隔在另一侧。她只在耳室门口看见过跪着的人形和石柱，听见铁链拖响便退回，不知道深处的机关与出口。隔门可以说话、递小物；要实际救人，仍须打通通路。她的油灯已熄灭，剩余燃料 60 分钟，没有火绒。是否同行、借灯与施救按人物资料。

## 主持与结局

叙述眼前可感知的事物，线索随观察出现。人物回应自己知道的事情，玩家提出行动后再裁定。观察与交谈不计时，具体探索动作计 1 回合，完整目标的必要步骤合并；多回合工序按原耗时。详见 [[guide/时间与并行]]。

现场记录、物品转移与伤势见 [[guide/当前状态]]；描写节奏见 [[guide/恐怖与节奏]]。

至少一名实际入场的宝藏猎人生还，且其中所有生还者抵达井外，才通关。NPC 与宝物不计通关条件。全灭，或确实无法救援且玩家明确放弃时失败。结算与结束流程见 [[guide/死亡与结局]]。
