---
name: 伤害
---

体力代表在危险中闪避、招架和承受冲击的余裕。体力耗尽仍可行动，但之后受到的伤害会直接损伤力量；恰好被伤害耗尽体力时，仍按伤疤规则处理。

## 伤害与两种触发

攻击直接掷伤害骰。实际伤害为 **max(0，骰点－目标护甲)**。宝藏猎人与人物的当前护甲由实际穿着的装备计算；皮甲提供 1，脱下或不再持有即不提供，以实际穿着为准。怪物继续使用自己的护甲资料。先扣当前体力，超出体力的余伤立即扣力量，数值最低为 0。保留受伤前体力，按以下顺序处理：

1. 力量降至 0：立即死亡。
2. **实际伤害超过受伤前体力，且力量仍大于 0：**先扣力量，再掷 1d20，用**受伤后的当前力量**做重伤豁免。1 总成功，20 总失败。体力已为 0 时受到正伤害，同样需要这次豁免。
3. **受伤前体力大于 0，实际伤害恰好等于该体力：**宝藏猎人按[[rule/伤疤]]查表，没有余伤，不额外做重伤豁免。NPC 与怪物不获得玩家伤疤。
4. 伤害不足以耗尽体力，或护甲把伤害减至 0：只处理实际扣值。

例如体力 3、力量 12、护甲 1，骰点 7：实际伤害 6，体力变为 0、力量变为 9，再以力量 9 做重伤豁免。骰点 4 则实际伤害 3，体力恰好归零，宝藏猎人查伤疤表第 3 项。

满载把体力压至 0 不是伤害，**不触发伤疤或重伤豁免**。体力 0 本身不等于死亡或不能行动；还须检查重伤、伤疤和属性限制。

## 重伤与救助

宝藏猎人与 NPC 重伤豁免成功时，保留力量损伤，不自动解除先前重伤。失败时陷入未稳定重伤，只能虚弱爬行，不能攻击、正常移动、攀井或自行完成救助。第一次未稳定时，须在 6 探索回合（约 60 分钟）内稳定伤势；再次受伤不能延后已有的较早期限。每次新受重伤都需要重新施救。

同伴施救后，伤者还须休息，普通重伤才能稳定。战斗中施救占一项行动，施救完成后，仍须脱离即时威胁并完成 1 探索回合休息；必须在死亡期限前完成。完成后伤势稳定，不再因本次失血期限死亡。力量损伤保留；稳定后按剩余属性及伤疤限制行动，体力恢复另按[[rule/休息与恢复]]。单纯喝水、吃饭、体力回满或站到井口不会自动稳定伤者。

未及时稳定者到期限时死亡，即使力量仍大于 0 也不能行动。伤疤第 11 项须实际治疗，第 12 项影响下一次重伤豁免，优先依伤疤规则处理。

力量 0 为死亡；敏捷 0 无法自行移动；意志 0 神志紊乱、无法行动。同伴可以搬运、保护和救出伤者，但伤者尚未死亡，并不代表能够自行攀井。结局见 [[rule/营救与结局]]。

## 怪物

怪物逐只结算伤害。体力归零不等于击败；余伤扣该成员力量，再以剩余力量做重伤豁免。失败便失去战斗能力；力量 0 同样击败。豁免成功且力量大于 0 者仍可行动，之后正伤害全扣力量并再次豁免。

怪物不查伤疤表。本次遭遇中重伤失能者视作已击败，不因重读或恢复光照复原。体力总量不等于仍能战斗的数量；危险是否清除取决于敌人的实际行动能力及隔离状态。
