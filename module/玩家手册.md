本模组使用简化改编的《石冢》（Cairn）第一版规则，仅用于快速体验 TARP 的冒险内容与玩法。游玩时以本手册和模组内规则为准，完整原版规则请参阅 Cairn 第一版 SRD。

你扮演一名前来古墓寻宝的宝藏猎人。

后山滑坡露出古墓，你为传闻中的宝藏而来。吕明亮和苏棠都是宝藏猎人，不限定过往出身。墓里传来一个陌生女子的求救声；是否帮忙、如何寻宝，由你决定。

开场时，你站在刚露出的墓门外。门缝可以侧身挤入，深处传来求救声。由你决定如何准备和入墓；入墓后退路坍塌，你们须另找出口。

## 行动与探索

主持人描述眼前的情况，你决定怎么做，并根据结果继续行动。直接说要做什么、看哪里、用什么，不必等主持人列选项。

例如：

- “我把火把举高，看看前面的路。”
- “我检查脚下的地砖。”
- “我先退回刚才的房间。”

也可以先问距离、位置或看得见的细节，再决定行动。

做法合理、结果没有悬念时直接成功；有危险或成败不定时，主持人根据现场决定豁免。你不必主动要求掷骰。

### 观察与记录

机关怎么运作、东西有什么用，要靠观察、尝试或询问来弄清楚。**看见某件东西，不等于知道它的原理或解法。**

资料卡只显示已发现的对象；尚未辨认的声音和痕迹记在地点观察中。地点描述保留已知线索，并随实际观察更新。

墓道沿一条路线深入，可以停下探查、做标记或退回已知安全处。处理过的机关保留实际状态，取走的物品不会重新出现。找到出口即可离开，不必取走所有宝物或击败所有怪物。

## 角色与豁免

选择吕明亮或苏棠，无须另行建角；可以独自入墓，也可与队友同行。

角色卡记录力量、敏捷、意志、体力和随身物品。

体力代表在危险中闪避、招架和承受冲击的余裕。体力耗尽仍可行动，但之后受到的伤害会直接损伤力量；恰好被伤害耗尽体力时，仍按伤疤规则处理。

| 属性 | 常见用途 |
| --- | --- |
| 力量 | 搬动、拖拽与抵抗 |
| 敏捷 | 闪避、攀爬与平衡 |
| 意志 | 抵抗恐惧和精神影响 |

### 骰子记法

d4、d6、d8 分别表示一颗四面、六面、八面骰，d20 是二十面骰；1d20 表示掷一次二十面骰。

### 豁免

豁免用来判断一项有风险的行动能否成功。

- 掷 **1d20**，小于或等于对应属性成功。
- 掷出 **1** 总是成功，掷出 **20** 总是失败。
- 共同承担同一次风险时，由最容易遇险的角色判定一次。

充分、合理的准备已经消除风险时直接成功，地点原有的判定也不例外。

## 回合与伤害

### 先攻与行动

战斗每轮约 **10 秒**。开战时，每名能行动的宝藏猎人分别做敏捷豁免，首轮按以下顺序行动：

1. 豁免成功的宝藏猎人。
2. 敌人。
3. 豁免失败的宝藏猎人。

**第二轮起，友方先行动，不再掷先攻。**突然遭遇或惊动墓中敌人时，也按上述顺序行动。

自己的回合可以移动约 **12 米**并做**一项行动**，每人每轮一次。

撤退行动先脱离交战、退到出口附近，完整穿行相邻路段仍按探索耗时。详见 [[rule/回合]]。

有些危险会先限制行动，在后续回合才造成伤害。被困或被缠住时，可尝试挣脱、求助或借地形阻挡敌人。战斗中也可尝试撤退，成败取决于处境。光源能照明，却未必能阻止怪物靠近。

### 攻击与扣伤

能够定位且够得着目标时，攻击直接掷武器标注的伤害骰，无需命中豁免。

1. 骰点减去护甲，得到实际伤害，最低为 0。
2. 先扣体力。
3. 同一次超出体力的余伤立即扣力量。

同一阶段多个攻击者攻击同一目标，各掷伤害只取最高值，再减护甲一次；双方都适用。

### 伤疤与重伤

- **伤害恰好把正数体力降至 0：**以实际伤害查 [[rule/伤疤]]，不另掷伤疤骰。
- **余伤扣除力量：**以受伤后的力量做重伤豁免。失败只能虚弱爬行，须在 **60 分钟内**获得救助与休息以稳定，否则死亡。
- **体力已为 0：**再次受到正伤害也需要做重伤豁免。

| 属性降至 0 | 后果 |
| --- | --- |
| 力量 | 立即死亡 |
| 敏捷 | 无法自行移动 |
| 意志 | 神志紊乱、无法行动 |

**体力耗尽仍可行动**，但重伤和伤疤造成的限制仍然有效。同伴可以搬运伤者。怪物同样要作重伤豁免，体力降至 0 并不代表已经被击败。

数值最低为 0，详见 [[rule/伤害]]。

## 行装、休息与口粮

### 行装

两人都携带 [[item/猎刀]]、[[item/探墓撬杆]]、皮甲、一包三次口粮、两支火把与火绒盒。吕明亮另带短弓和三支猎箭，苏棠另带可承重一人的十米绳索。旅行行囊、刀鞘与日常衣物属于收纳和衣着，不另提供防护、工具能力或额外占格。

每人 **10 格行装**，通常每件占 1 格，笨重物品占 2 格。随身物品全部占格，放下或转交后才移出行装。

- **皮甲：**吕明亮与苏棠开局各自穿好一件 [[item/皮甲]]，护甲均为 1，行装均为 8 格。伤害骰点先减护甲；脱下仍带着继续占格，但不再减伤。转交后接收者要实际穿上才有防护。
- **满载：**体力降至 0 且不能恢复，这本身不是力量伤害。
- **拿取物品：**已辨认物品将导致满载时，主持会先说明后果，由你决定拿取、分配或放弃。
- **卸下负担：**不会立即恢复体力。

详见 [[rule/行装]]。

### 休息

脱离追击、确认没有即时威胁后，可短休 **10 分钟**恢复全部体力。匮乏或满载时不能恢复。

力量等属性损伤不能靠墓内短休恢复。重伤须实际施救后休息才能稳定，伤疤按各自条件恢复。

默认随身饮水足够完成一次地穴探索，详见 [[rule/休息与恢复]]。

### 口粮与匮乏

开局时你已经吃饱，也休息过。一包 [[item/口粮]] 可以吃 **3 次**，每次供一人吃饱，维持 **6 小时**。

给同伴吃也扣除一次剩余次数；还没饿时，短休不用再吃。

饥饿或连续 **24 小时**未睡眠会进入匮乏，不能恢复体力。饥饿、缺眠和匮乏由探索回合自动计算，不需要逐次设置状态；本短篇不累积长时疲乏。部分伤疤也会导致匮乏，吃饭不能解除。

详见 [[rule/饥饿与匮乏]]。

## 光照与时间

### 光源与黑暗

墓内没有固定灯火。每人带两支未点燃的 [[item/火把]] 与 [[item/火绒盒]]。

每支火把占 **1 格**，累计燃烧 **6 探索回合（约 60 分钟）**，照亮身旁约 **6 米**。同伴可共用光源；熄灭保留余量，重新点燃不会补回燃料。

无光时只能靠声音、气味、触感和记忆行动，无法辨认新的文字、记号或远处细节，已揭露地点的场景图仍可作为参考，当前可感知内容以主持描述为准。安全与否取决于地形和准备；黑暗本身不会自动引发恐慌。

### 探索耗时

| 行动 | 通常耗时 |
| --- | --- |
| 有光时移至相邻地点 | 1 探索回合（10 分钟） |
| 摸黑移至相邻地点 | 2 探索回合（20 分钟） |
| 试探、搜索、靠近、开门、跳跃、递物或操作光源 | 1 探索回合（10 分钟） |
| 处理机关或短休 | 通常 1 探索回合（10 分钟） |
| 观察、纯交谈、讨论方案或询问已知信息 | 不耗回合 |
| 通常一场战斗 | 结束时统一计 1 探索回合 |

观察不计时，其他具体探索动作各计一回合，免骰也计时；完整行动的必要步骤合并结算，独立行动分别计时。已有多回合耗时的行动按原规定执行。经过分钟、饥饿和点燃火把的余量自动计算。

分队共用时间轴，每段按最长耗时推进，先完成者等到段末；不按人数或场景数累加，也不在段中插入新行动。多回合行动逐回合检查危险。

详见 [[rule/光照]]。

## 探险与结局

- **通关：**至少一名宝藏猎人生还，且所有仍活着的入墓宝藏猎人都抵达井外安全处。
- **失败：**队伍全灭。
- **被困：**确实无法继续行动或救援，且玩家明确放弃尝试后，以被困结束；尚活着的角色不会因此被算作死亡。

还有活着的队员留在墓里，冒险就继续，你可以返回帮忙，也可以提出其他救援办法。

伤员不能自己爬井时，需要同伴保护和搬运。每名不能自行攀爬者额外花 **10 分钟**，伤势期限照常流逝。

你们不必拿宝物或击败全部怪物，入口封闭后也不能补入新角色。

NPC 由主持控制，可参战、受伤或阵亡。结局交代其去留和带走的财物，生死不影响通关。

本次冒险以简短尾声结束，不再展开出墓后的康复；本局没有数值成长，伤疤不会改变体力或属性上限。详见 [[rule/营救与结局]]。
